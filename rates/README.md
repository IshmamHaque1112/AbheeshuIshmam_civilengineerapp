# Cost and labor rates

Placeholder cost and crew-productivity figures used by `cornerbrief/cost.py`
for rough, explicitly-labeled cost estimates. These are **not market
prices** - see the main `README.md`'s "Cost and labor" section for how
they're presented to a user (durations and crews stay "unknown," dollars
are hidden).

- `cost_*.yaml` - placeholder unit costs (curb, DWS, ramp concrete, removal)
- `crew_*.yaml` - placeholder crew productivity rates (cement mason, laborer, mason)
