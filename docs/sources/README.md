All nine sheets are saved here. Sheets 2 to 9 are transcribed in [`H-1011-sheets-2-9.md`](H-1011-sheets-2-9.md): every note word for word, the tables, and the labeled dimensions and slopes from each view. Claude made the transcription on November 9, 2026, and no person has checked it yet.

Four reference rules cite it: `H1011-S2-C2-TABLE2`, `H1011-S4-C4-C5-APPROVAL`, `H1011-S3-GUTTER-MIN` and `H1011-S9-DWS-LENGTH`. They are unreviewed and add no numeric checks, because the dataset doesn't say which case drawing a ramp follows. `H1011-SHEETS-2-9` stays open until a reviewer confirms the transcription.
